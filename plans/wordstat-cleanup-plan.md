# План очистки данных Wordstat

## Цель
Очистить 966 реальных запросов из Яндекс Wordstat, отсортировать по частотности и создать 3 файла.

## Архитектура решения

### Подход: Python-скрипт
Написать скрипт `PLAN_SEO/WORDS/clean_wordstat.py`, который:
1. Читает все 7 .txt файлов
2. Применяет правила фильтрации
3. Генерирует `CLEAN_ALL.md`
4. Выводит статистику для обновления других файлов

### Формат входных файлов
```
запрос\tчастотность
```
(табуляция разделитель, частотность — число)
