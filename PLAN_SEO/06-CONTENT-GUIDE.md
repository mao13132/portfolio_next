## 1. Общие принципы

**Аудитория:** Владельцы МСБ, маркетологи, селлеры, IT-менеджеры. Уровень: новичок–средний.
**Тон:** Профессиональный, но доступный. Без воды. Конкретные цифры и кейсы.
**Цели:** Топ-5 Яндекса → CTA (заявка/переход на money page) → полный ответ читателю.

### Источники данных (КРИТИЧЕСКИ ВАЖНО)

✅ **Разрешено:** Wordstat (`WORDS/CLEAN_ALL.md`), реальные кейсы (`bad_works_.py`), документация API, личный опыт.
❌ **Запрещено:** Выдуманные частотности, статистика без источника, выдуманные кейсы.
❌ **НЕ вставлять в текст статьи:** Упоминания Wordstat, «показов/мес», SEO-термины. Wordstat — только для планирования.

## 2. Структура статьи

**Обязательные элементы:**
1. Title (50-70 символов) | Meta Description (150-160 символов с CTA)
2. H1 (один, с основным ключом) | Введение (150-250 слов)
3. Основной контент: 8-12 H2 секций + H3 подсекции
4. Заключение (100-200 слов + CTA) | FAQ (4-6 вопросов)

**Длина:**

| Тип | Объём |
|-----|-------|
| Локомотив (ВЧ) | 5 000-8 000 слов |
| Спутник (СЧ) | 3 500-5 000 слов |
| Длинный хвост (НЧ) | 2 000-3 500 слов |
| **Минимум** | **2 500 слов** |

---

## 3. Ключевые слова

| Место | Приоритет |
|-------|-----------|
| Title (в начале) | ★★★ |
| H1 | ★★★ |
| Первый абзац (первые 100 слов) | ★★★ |
| H2 заголовки | ★★ |
| Meta Description + CTA | ★★ |
| URL (транслит) | ★★ |
| Alt теги | ★ |

**Плотность:** Основной ключ 3-5 раз на 4 000 слов. Не переспамить!

---

## 4. Внутренние ссылки

| Тип | Кол-во | Где |
|-----|--------|-----|
| На money page | 2-3 | В тексте + CTA |
| На соседние статьи кластера | 2-3 | Контекстно |
| Cross-link на другой кластер | 1-2 | Где уместно |
| **ИТОГО** | **5-8** | |

**Правила:** Анкоры — ключевые фразы (НЕ «тут»/«подробнее»). Ссылки контекстуальны.

**Формат в text parts:** Ссылки вставляются прямо в `content` секции как Markdown `[текст](/url)`.
**Readmore блок:** 4-6 ссылок, в доменном файле, перед FAQ.
**Conversion блок:** 2-3 на статью, ссылка на money page кластера.

## 7. FAQ

- 4-6 вопросов на статью, на естественном языке
- Ответы 2-4 предложения, содержат ключевые слова
- Разметка Schema.org FAQPage (генерируется автоматически из массива `faq`)
- Источники: Wordstat (вопросительные), «Люди также спрашивают», реальные вопросы клиентов

## 8. Процесс написания

1. **Исследование (30-60 мин):** Wordstat + анализ топ-10 Яндекса + пробелы
2. **Структура (30 мин):** H2-H3 план, ключевые слова, FAQ, ссылки
3. **Написание (3-6 ч):** AI-черновик → проверка фактов → добавить кейсы/опыт → CTA
4. **Оптимизация (30-60 мин):** Title, Description, ключевые слова, ссылки, CTA, alt
5. **Публикация (30-60 мин):** Доменный файл `.ts` + text parts + registry → деплой → индексация

## 10. Использование AI

1. **Подготовить промпт:** тема, ключи, структура H2-H3, аудитория, тон, объём
2. **Сгенерировать черновик:** 3 000-5 000 слов
3. **Редактура (ОБЯЗАТЕЛЬНО):** проверить факты, добавить опыт/кейсы, убрать воду, переписать введение, добавить ссылки/CTA
4. **Оптимизация:** ключевые слова, Title, Description, структура
5. ❌ Не публиковать AI-текст без редактуры. AI не даёт реальные кейсы и экспертное мнение.

## 11. Обновление статей

**Когда:** Потеря позиций, 6+ месяцев, новые ключи, конкуренты обновились, изменились цены.
**Как:** Обновить `modifiedDate`, добавить секции (не удалять), обновить данные/ссылки/FAQ, переиндексировать.
