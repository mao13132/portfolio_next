## 1. Общие принципы

### 1.1. Для кого пишем

**Целевая аудитория:**
- Владельцы малого и среднего бизнеса в России
- Маркетологи и менеджеры по продажам
- Селлеры на маркетплейсах
- Предприниматели, которые ищут автоматизацию
- IT-менеджеры и CTO

**Уровень технической подготовки:** от новичка до среднего. Объясняем сложные вещи простым языком.

### 1.2. Тон и стиль

- **Профессиональный, но доступный** — не перегружать терминами
- **Практичный** — каждый абзац даёт ценность
- **Конкретный** — цифры, примеры, кейсы
- **Экспертный** — показываем знание предмета
- **Без воды** — каждый абзац должен нести смысл

### 1.3. Цели статьи

1. **SEO-цель:** Занять позицию в топ-5 Яндекса по целевым запросам
2. **Бизнес-цель:** Привести читателя к CTA (заявка, переход на money page)
3. **Пользовательская цель:** Дать полный ответ на вопрос читателя

### 1.4. Источники данных (КРИТИЧЕСКИ ВАЖНО)

⚠️ **Все данные в статьях должны быть верифицированы.**

**Разрешённые источники:**
- Яндекс Wordstat — реальные частотности (файл `PLAN_SEO/WORDS/CLEAN_ALL.md`)
- Реальные кейсы из портфолио (файл `PLAN_SEO/bad_works_.py`)
- Общедоступные факты (документация API, цены сервисов)
- Личный опыт разработчика

**Запрещено:**
- Выдуманные частотности запросов
- Выдуманная статистика без источника
- Выдуманные кейсы
- Общие фразы без основы

**Подробнее:** `PLAN_SEO/WORDSTAT-RULES.md`

## 2. Структура статьи

### 2.1. Обязательные элементы

```
1. Title (50-70 символов)
2. Meta Description (150-160 символов)
3. H1 (один на страницу, содержит основной ключ)
4. Введение (150-250 слов)
   - Кратко о чём статья
   - Для кого
   - Что узнает читатель
5. Основной контент (H2 + H3 блоки)
   - 8-12 секций (H2)
   - Подсекции (H3) где нужно
6. Заключение (100-200 слов)
   - Резюме
   - CTA
7. FAQ (4-6 вопросов)
8. Schema.org разметка
```

### 2.2. Рекомендуемая структура H1-H3

```
H1: Основной заголовок с ключевым словом

  H2: Что это такое / Определение
    (150-300 слов — объяснение для новичков)

  H2: Зачем это нужно / Преимущества
    H3: Преимущество 1
    H3: Преимущество 2
    H3: Преимущество 3
    (300-500 слов)

  H2: Как это работает / Процесс
    H3: Шаг 1
    H3: Шаг 2
    H3: Шаг 3
    (400-600 слов)

  H2: Примеры / Кейсы
    H3: Пример 1: описание
    H3: Пример 2: описание
    (300-500 слов)

  H2: Стоимость / Цена
    (200-400 слов — обоснование цен)

  H2: Как выбрать / На что обратить внимание
    (200-400 слов)

  H2: Часто задаваемые вопросы (FAQ)
    (4-6 вопросов с ответами)

  H2: Заключение
    (100-200 слов + CTA)
```

### 2.3. Длина статьи

| Тип статьи | Рекомендуемый объём | Примечание |
|------------|-------------------|------------|
| Локомотив (ВЧ запрос) | 5 000 - 8 000 слов | Подробное руководство |
| Спутник (СЧ запрос) | 3 500 - 5 000 слов | Конкретная тема |
| Длинный хвост (НЧ) | 2 000 - 3 500 слов | Узкая тема |
| Кейс-стади | 2 000 - 3 000 слов | Конкретный пример |

**Минимум:** 2 500 слов (меньше — не будет ранжироваться по конкурентным запросам)
**Оптимум:** 4 000 - 6 000 слов

## 3. Ключевые слова

### 3.1. Где размещать ключевые слова

| Место | Требование | Приоритет |
|-------|-----------|-----------|
| Title | Основной ключ в начале | ★★★ |
| H1 | Основной ключ | ★★★ |
| Первый абзац | Основной ключ (первые 100 слов) | ★★★ |
| H2 заголовки | Вторичные ключи | ★★ |
| Meta Description | Основной ключ + CTA | ★★ |
| Alt теги изображений | Ключевое слово (где уместно) | ★ |
| URL | Транслит ключевого слова | ★★ |
| Текст статьи | Естественное распределение | ★★ |

### 3.2. Плотность ключевых слов

- **Основной ключ:** 3-5 раз на 4 000 слов (0.1-0.15%)
- **Вторичные ключи:** 2-3 раза каждый
- **LSI-слова:** естественно в тексте

**Важно:** Не переспамить! Текст должен читаться естественно. Яндекс негативно относится к переоптимизации.

### 3.3. Типы ключевых слов

**Основной ключ (1 на статью):**
- Самый частотный запрос кластера
- Пример: «парсер wildberries»

**Вторичные ключи (3-5 на статью):**
- Вариации основного ключа
- Пример: «парсер товаров wildberries», «сбор данных wildberries», «парсинг wildberries python»

**LSI-слова (10-20 на статью):**
- Тематически связанные слова
- Пример: «селлер», «карточка товара», «аналитика продаж», «мониторинг цен», «API маркетплейса»

### 3.4. Формула заголовка

**Title формула:**
```
[Основной ключ]: [Описание/Выгода] | DimaRazrab
```

Примеры:
- `Парсер Wildberries: как собрать данные о товарах и ценах | DimaRazrab`
- `Telegram-бот для бизнеса: полное руководство по созданию | DimaRazrab`
- `Лидогенерация в Telegram: автоматический поиск клиентов | DimaRazrab`

**H1 формула:**
```
[Основной ключ]: [Подробное описание]
```

Примеры:
- `Парсер Wildberries: полное руководство по сбору данных`
- `Telegram-бот для бизнеса: зачем нужен и как создать`
- `Лидогенерация в Telegram: как найти клиентов автоматически`

| Тип ссылки | Количество | Где размещать |
|-----------|------------|---------------|
| На money page (коммерческая) | 2-3 | В тексте + CTA в конце |
| На соседние статьи кластера | 2-3 | В тексте, контекстно |
| На статьи другого кластера | 1-2 | В тексте, где уместно |
| **ИТОГО** | **5-8** | |

### 4.2. Формат ссылок

**Правильно:**
```markdown
Подробнее о [разработке Telegram-ботов на заказ](/razrabotka-botov) 
вы можете прочитать в нашем руководстве.
```

**Неправильно:**
```markdown
Подробнее [тут](/razrabotka-botов).
```

### 4.3. Анкоры

- Использовать ключевые фразы как анкоры
- Не использовать «тут», «здесь», «подробнее»
- Анкор должен быть релевантен странице, на которую ведёт

## 9. Процесс написания статьи

### Шаг 1: Исследование (30-60 мин)

1. Открыть Яндекс Вордстат
2. Вбить основной ключевой запрос
3. Собрать все варианты запросов
4. Проанализировать топ-10 Яндекса по запросу
5. Определить, какие темы покрывают конкуренты
6. Найти пробелы (что не покрыто)

### Шаг 2: Структура (30 мин)

1. Составить план H2-H3
2. Определить ключевые слова для каждого H2
3. Подготовить FAQ (4-6 вопросов)
4. Определить, на какие страницы будут ссылки

### Шаг 3: Написание (3-6 часов)

1. Написать введение (150-250 слов)
2. Написать каждый H2-блок
3. Добавить примеры и кейсы
4. Написать заключение с CTA
5. Написать FAQ

**С использованием AI:**
1. Сгенерировать черновик через AI (ChatGPT, Claude)
2. Проверить факты и цифры
3. Добавить свой опыт и экспертность
4. Переписать вводные фразы
5. Добавить конкретные примеры из практики

### Шаг 4: Оптимизация (30-60 мин)

1. Проверить Title (50-70 символов, ключ в начале)
2. Проверить Meta Description (150-160 символов, CTA)
3. Проверить H1 (содержит основной ключ)
4. Проверить плотность ключевых слов
5. Добавить внутренние ссылки (5-8 штук)
6. Добавить CTA (2-3 места)
7. Проверить изображения (alt, размер)

### Шаг 5: Публикация (30-60 мин)

1. Создать доменный файл `[slug].ts`
2. Создать текстовые файлы `texts/[slug]-part1.ts` и `part2.ts`
3. Добавить в реестр статей (`registry.ts`)
4. Проверить локально
5. Задеплоить
6. Отправить URL в Яндекс.Вебмастер на индексацию

## 12. Использование AI для написания

### 12.1. Рекомендуемый процесс

1. **Подготовка промпта:**
   - Указать тему и ключевые запросы
   - Указать структуру H2-H3
   - Указать целевую аудиторию
   - Указать тон (экспертный, но доступный)
   - Указать объём

2. **Генерация черновика:**
   - Сгенерировать через AI (ChatGPT, Claude)
   - Получить 3 000 - 5 000 слов

3. **Редактура (ОБЯЗАТЕЛЬНО):**
   - Проверить факты и цифры
   - Добавить свой опыт и кейсы
   - Удалить воду и общие фразы
   - Добавить конкретику (цифры, примеры)
   - Переписать введение и заключение
   - Добавить внутренние ссылки
   - Добавить CTA

4. **Оптимизация:**
   - Проверить ключевые слова
   - Проверить Title и Description
   - Проверить структуру

### 12.2. Чего НЕ делать

- ❌ Публиковать AI-текст без редактуры
- ❌ Использовать AI-генерированные факты без проверки
- ❌ Копировать текст конкурентов
- ❌ Писать только ради ключевых слов (без пользы для читателя)
- ❌ Использовать один и тот же шаблон для всех статей

### 12.3. Чем AI помочь НЕ МОЖЕТ

- Реальные кейсы и опыт
- Уникальные инсайты
- Экспертное мнение
- Конкретные цены и сроки (нужно вставить вручную)
- Скриншоты и примеры из реальных проектов

|--------|----------|

4. Добавить новые внутренние ссылки
5. Обновить FAQ (если появились новые вопросы)
