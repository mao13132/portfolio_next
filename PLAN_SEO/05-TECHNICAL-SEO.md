## Требования по элементам

### 3. Мета-теги
- `<title>` — уникальный, 50-70 символов, ключевое слово в начале
- `<meta description>` — уникальный, 150-160 символов, CTA
- `<link rel="canonical">` — на каждой странице

### 4. Open Graph
- og:title, og:description, og:image (1200×630), og:url, og:type, og:locale, og:site_name

### 6. Schema.org
- **Статьи:** Article + FAQPage + BreadcrumbList — ✅ реализовано
- **Коммерческие:** Service + BreadcrumbList — реализовано
- **Главная:** ProfessionalService — реализовано
- Проверка: https://search.google.com/test/rich-results

### 7. Core Web Vitals
| Метрика | Цель | Инструмент |
|---------|------|------------|
| LCP | < 2.5 сек | PageSpeed Insights |
| FID | < 100 мс | PageSpeed Insights |
| CLS | < 0.1 | PageSpeed Insights |
| TTFB | < 800 мс | WebPageTest |

**Оптимизация:** next/image (WebP), next/font, dynamic() для тяжёлых компонентов, ISR/SSG, CDN.

### 8. Мобильная адаптация
- viewport meta тег, текст ≥ 16px, кнопки ≥ 44×44 px, нет горизонтальной прокрутки

### 10. Внутренняя перелинковка (🔴 КРИТИЧНО)
- 2-3 ссылки на money page из каждой статьи
- 2-3 ссылки на соседние статьи кластера
- 1-2 кросс-ссылки на другие кластеры
- Анкоры — ключевые фразы (не «подробнее»)
- Hub-страницы → все статьи кластера + money page

### 11. Alt теги
- Каждое изображение имеет alt, ≤ 125 символов, содержит ключевое слово где уместно

### 12. ЧПУ URL
- Транслит, без спецсимволов/ID, содержат ключевое слово

### 14. Редиректы
- 301 non-www → www, HTTP → HTTPS, нет цепочек редиректов, trailing slash консистентность

### 15. Дополнительно
- Заголовки безопасности (X-Content-Type-Options, X-Frame-Options)
- `<html lang="ru">`
- Favicon все размеры (16, 32, 192, 512)
