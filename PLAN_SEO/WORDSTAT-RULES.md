# ⚠️ Правила верификации данных для SEO-статей

> **ГЛАВНОЕ ПРАВИЛО: НИКАКИХ ВЫДУМАННЫХ ДАННЫХ!**
> Если данных нет — НЕ ПИШЕМ статью.
> 01.08.2026

---

## ✅ Что МОЖНО использовать

- **Wordstat** — реальные частотности (`WORDS/CLEAN_ALL.md`)
- **Кейсы из портфолио** — ROI, сроки, результаты (`bad_works_.py`)
- **Общедоступные факты** — документация API, цены сервисов
- **Личный опыт** — реальные проекты, сроки, проблемы

## ❌ Что НЕЛЬЗЯ использовать

- Упоминания Wordstat в тексте статьи («по данным Wordstat», «показов/мес»)
- Выдуманные частотности, статистика без источника
- Выдуманные кейсы, цены конкурентов, сроки
- Общие фразы без основы («эксперты говорят»)

> Wordstat — ТОЛЬКО для SEO-планирования, НЕ для текста статьи!

## Чеклист перед публикацией

| # | Проверка |
|---|----------|
| 1 | Все частотности — из Wordstat или отмечены как «оценка» |
| 2 | Все кейсы — реальные проекты из портфолио |
| 3 | Все цены — реальные цены разработчика |
| 4 | Все сроки — реальные из опыта |
| 5 | Нет выдуманной статистики |
| 6 | Нет общих фраз без основы |
| 7 | Технические данные — из документации |
| 8 | В тексте статьи НЕТ упоминаний Wordstat/частотностей |
