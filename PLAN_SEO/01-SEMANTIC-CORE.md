## Методология оценки частотности

Частотность указана по логике Яндекс Вордстат (показов в месяц по России, без кавычек — то есть включая все словоформы и дополнительные слова). Оценки основаны на типичных данных для B2B IT-услуг в российском сегменте:

| Маркер | Частотность | Пример |
|--------|-------------|--------|
| ВЧ | 1000+ | «создание сайта» |
| СЧ | 200-999 | «разработка telegram бота» |
| НЧ | 50-199 | «telegram бот для записи клиентов» |
| СНЧ | 10-49 | «aiogram 3 разработка» |
| МНЧ | 1-9 | «парсер отзывов wildberries api» |

**Типы запросов:**
- **инфо** — информационный (человек ищет информацию)
- **ком** — коммерческий (человек сравнивает предложения)
- **транз** — транзакционный (человек готов купить/заказать)

**Приоритет:**
- ★★★ — немедленно (высокий спрос + низкая конкуренция + прямое соответствие услугам)
- ★★ — средний (хороший потенциал, реализовать в фазе 2)
- ★ — низкий (дополнительный трафик, реализовать в фазе 3)

## Примечания

1. **Частотность** — оценки основаны на типичных данных Яндекс Вордстат для B2B IT-услуг. Точные данные можно получить только через прямой парсинг Вордстат или сервисы Keys.so / Serpstat.

2. **Приоритет ★★★** — запросы, по которым нужно продвигаться в первую очередь: высокий коммерческий intent, реалистичная конкуренция, прямое соответствие услугам.

3. **Длинный хвост** — многие НЧ/СНЧ запросы имеют очень низкую конкуренцию и могут выйти в топ-5 Яндекса в течение 1-3 месяцев при качественном контенте.

4. **Пересечения кластеров** — некоторые запросы пересекаются (например, «telegram бот для лидогенерации» = кластер A + C). Это нормально и обеспечивает кросс-линковку.

5. **Неучтённые запросы** — реальное семантическое ядро будет ещё больше за счёт:
   - Гео-запросов («разработка telegram бота москва»)
   - Сезонных запросов
   - Новых запросов, связанных с AI (быстрый рост)
   - Вопросительных запросов («как», «зачем», «почему»)
