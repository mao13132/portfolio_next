# 📐 Методология расширения семантических кластеров

> Принцип: люди ищут решение СВОЕЙ БОЛИ, а не название услуги.
> "Заказать бота" — это финальный запрос. До него — путь через боли, вопросы, сравнения.
> 
> Все запросы ДОЛЖНЫ быть верифицированы через Wordstat перед созданием контента.

---

## 1. Типы запросов (воронка клиента)

### Уровень 1: Проблема (информационный)
Человек ещё не знает что ему нужен бот. Он ищет решение проблемы.
Примеры: "как автоматизировать запись клиентов", "теряю клиентов в telegram"

### Уровень 2: Решение (коммерческий)
Человек понял что нужна автоматизация, ищет варианты.
Примеры: "бот для записи клиентов", "автоматизация заявок telegram"

### Уровень 3: Заказ (транзакционный)
Человек готов купить, ищет исполнителя.
Примеры: "заказать telegram бота", "разработка бота цена"

### Уровень 4: Отраслевой
Человек ищет решение для своей конкретной отрасли.
Примеры: "telegram бот для стоматологии", "бот для салона красоты"

### Уровень 5: Гео
Человек ищет исполнителя в своём городе.
Примеры: "разработка ботов москва", "создать telegram бота спб"

## 5. Как применять методику

### Для каждого кластера:

1. **Собрать запросы-боли** — как клиент описывает свою проблему
2. **Собрать отраслевые запросы** — "[услуга] для [отрасли]"
3. **Собрать проблемно-ориентированные** — "как [решить проблему]"
4. **Верифицировать через Wordstat** — записать реальные частотности
5. **Написать статьи** — по верифицированным запросам, с кейсами

### Формула статьи:
- **Заголовок** = боль или отраслевой запрос
- **Введение** = описание боли читателя
- **Основной текст** = решение + кейсы из портфолио
- **CTA** = "Напишите мне — решу вашу задачу"

### Приоритет расширения:

1. **Первый волн** — отрасли с реальными кейсами (салоны красоты, ветклиники, образование, психологи, недвижимость, маркетплейсы, Avito)
2. **Вторая волна** — отрасли с высоким спросом без кейсов (стоматологии, рестораны, фитнес)
3. **Третья волна** — проблемно-ориентированные запросы (боли клиентов)
