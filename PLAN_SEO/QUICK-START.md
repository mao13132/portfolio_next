## 2. Система работы

Файл `ROO-TASKS.md` — трекер задач. RooCode при каждом запуске: читает → находит `[ ]` → выполняет → ставит `[x]` → следующая.

Формат: `- [ ] Задача` / `- [-] В процессе` / `- [x] Выполнено`

## 3. Готовые промпты

### Промпт 1: Техническая оптимизация
```
Прочитай PLAN_SEO/05-TECHNICAL-SEO.md и PLAN_SEO/ROO-TASKS.md.
Выполни первый невыполненный пункт из технического чеклиста.
После выполнения обнови статус в ROO-TASKS.md на [x].
```

### Промпт 2: Создание коммерческой страницы
```
Прочитай PLAN_SEO/02-PAGE-PLAN.md, ROO-TASKS.md, 06-CONTENT-GUIDE.md.
Найди следующую коммерческую страницу для создания (статус [ ]).
Создай в pages/ по образцу существующих (razrabotka-botov.tsx).
Требования: Title+Description с ключами, H1, H2/H3, CTA, Schema.org Service.
После создания обнови ROO-TASKS.md.
```

### Промпт 3: Написание SEO-статьи
```
Прочитай ROO-TASKS.md, 06-CONTENT-GUIDE.md, 01-SEMANTIC-CORE.md, ARTICLE-CHECKLIST.md.
Найди следующую статью. Напиши статью:
- Ответ в первые 30 секунд, лучше конкурентов из топ-10
- Реальные примеры и кейсы, таблицы, ответы на возражения
- МИНИМУМ 8000 символов, проходит ВСЕ 25 критериев
- Сохрани в data/articles_data/ как .ts
После написания обнови ROO-TASKS.md.
```
