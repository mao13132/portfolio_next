## 2. ⚙️ Система работы с RooCode

### 2.1. Файл-трекер `PLAN_SEO/ROO-TASKS.md`

**Суть:** Создаётся файл `ROO-TASKS.md` со списком всех задач. RooCode при каждом запуске читает его, находит первую задачу со статусом `[ ]`, выполняет её, ставит `[x]` и переходит к следующей.

**Почему это круто:**
- Закрыл VSCode → открыл → RooCode продолжает с места остановки
- Видно прогресс: сколько сделано, сколько осталось
- Можно вручную менять приоритеты, переставляя задачи

**Формат задач:**
```
- [ ] Задача, которую ещё не начали
- [-] Задача в процессе (RooCode ставит, когда начинает)
- [x] Задача выполнена (RooCode ставит, когда закончил)
ВСЕ ЗАДАЧИ КОТОЫРЕ ЗАКОНЧИЕНЫ ОТПРАВЛЯЙ В SUCCESS.md туда вырезай из файлов строчки если задача закрыта. Что бы файлы худели
```

**Пример структуры файла:**
```markdown
# 📋 RooCode Tasks — SEO DimaRazrab.com

> RooCode: читай этот файл в начале каждой сессии. Выполняй первую задачу [ ].
> После выполнения ставь [x] и переходи к следующей.
```

### 2.2. Правила для RooCode

RooCode умеет читать файлы с правилами. Есть два способа их передать:

#### Способ A: Файл правил (рекомендуется)

Создай файл `.roo/rules/seo-rules.md` с таким содержимым:

```markdown
# Правила для SEO-задач

## Обязательные действия в начале сессии:
1. Прочитай файл PLAN_SEO/ROO-TASKS.md
2. Найди первую задачу со статусом [ ]
3. Поставь ей статус [-]
4. Выполни задачу
5. Поставь статус [x]
6. Если задача большая — разбей на подзадачи в файле

## Правила выполнения:
- Одна задача за раз. Не бросай на половине.
- После создания страницы/статьи — обнови PLAN_SEO/ROO-TASKS.md
- Не отклоняйся от плана в ROO-TASKS.md
- Все страницы — в папку pages/
- Все статьи — в папку data/articles_data/
- Используй существующие компоненты и стили проекта

## Референсы:
- Семантическое ядро: PLAN_SEO/01-SEMANTIC-CORE.md
- План страниц: PLAN_SEO/02-PAGE-PLAN.md
- Технический чеклист: PLAN_SEO/05-TECHNICAL-SEO.md
- Гайд по статьям: PLAN_SEO/06-CONTENT-GUIDE.md
```

#### Способ B: Промпт в начале сессии

Если не хочешь создавать файл правил, просто вставляй в начало каждого промпта:

```
Перед выполнением задачи: прочитай PLAN_SEO/ROO-TASKS.md, 
найди первую задачу [ ], поставь [-], выполни, поставь [x].
```

## 4. 🎯 Как выбирать темы статей

Не пиши статьи наугад. Вот алгоритм:

### Шаг 1: Открой семантическое ядро
Открой `PLAN_SEO/01-SEMANTIC-CORE.md` и найди раздел с запросами.

### Шаг 2: Отфильтруй по приоритету
Ищи запросы с **★★★** — это самые приоритетные.

### Шаг 3: Проверь критерии

| Критерий | Что проверять |
|----------|--------------|
| Тип запроса | Коммерческий лучше информационного |
| Конкуренция | НЧ/СЧ запросы — легче попасть в топ |
| Соответствие услугам | Запрос должен вести на твою услугу |
| Потенциал конверсии | Читатель статьи → клиент |

### Шаг 4: Попроси RooCode

```
Прочитай PLAN_SEO/01-SEMANTIC-CORE.md. 
Предложи ТОП-10 самых приоритетных тем для статей:
- Коммерческие запросы ★★★
- Низкая/средняя частотность
- Соответствуют услугам: боты, парсинг, лидогенерация, автоматизация

Для каждой темы укажи: запрос, кластер, предполагаемый URL статьи.
```

### Шаг 5: Добавь в трекер
После того как RooCode предложит темы — попроси его добавить их в `ROO-TASKS.md`.
